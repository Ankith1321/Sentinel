# Sentinel — frontend

Next.js chat UI for Sentinel. See the [root README](../README.md) and [`docs/CONTEXT.md`](../docs/CONTEXT.md) for the full project.

## Dev

```bash
npm install
npm run dev
```

Open http://localhost:3000.

Note: the API base URL is currently hardcoded in `src/app/page.tsx` instead of read from `NEXT_PUBLIC_API_URL` — see `docs/SENIOR_REVIEW.md` item 9.
